Privacy Policy

Last updated: 2026-11-19. Deutsche Fassung: Datenschutzerklärung.

1. Who is responsible

Luis Fricker, contact: luissecomstore@gmail.com. AutoClip Business is software that runs locally on the computer of its owner. The operator does not run a server that receives users' data.

2. Google and YouTube data the application accesses

DataAPI callPurpose

The application does not read other users' data, comments, watch history, subscriptions or analytics, and does not access any other Google service.

3. OAuth permissions used

  • youtube.upload
  • youtube.readonly

No other scopes are requested.

4. How tokens are stored

The refresh token, the OAuth client configuration and the channel ID are stored in the macOS Keychain on the owner's computer. Short-lived access tokens exist only in the memory of the running process. The OAuth client file may also exist in the application's local config folder with owner-only file permissions. Nothing is stored on any server operated by the developer, and no tokens are published or embedded in this website.

5. Sharing with third parties

No Google user data is sold, shared with, or transferred to third parties, and none is used for advertising, profiling or the training of AI models. The only network communication involving Google data is between the owner's computer and Google/YouTube APIs. The application contains no analytics or tracking. Video analysis, including speech transcription, runs locally on the owner's computer.

Limited Use: AutoClip Business's use and transfer to any other app of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Data is used only to provide the user-facing upload feature described above.

6. How long data is kept

Tokens and the channel ID stay in the Keychain until the owner removes them (section 7). The local database keeps the public URLs and status of uploaded videos until the owner deletes it. Access tokens are discarded when the process ends or after about one hour.

7. Revoking access and deleting data

  • Revoke at Google: myaccount.google.com/permissions → AutoClip Business → Remove access.
  • Revoke and delete locally: run .venv/bin/python bin/revoke_local.py in the application folder. It revokes the refresh token at Google and deletes the Keychain entries.
  • Delete local records: delete the data and output folders. Videos already uploaded to YouTube remain on the owner's channel until deleted in YouTube Studio.

8. This website

This website consists of static pages and uses no cookies, analytics or forms. It is hosted by GitHub Pages, which may process technical server logs (such as IP addresses) under its own privacy policy.

9. Children

The application is not directed at children.
